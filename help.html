SmartLib - Integrated Library Management System

A full-stack, automated library software platform designed for academic colleges, universities, and schools. Implemented using modern vanilla JavaScript, Express.js REST API micro-services, and persistent SQLite database storage.

System Architecture

  • Frontend: Semantic HTML5, CSS3 Variables, Responsive Flex/Grid, Vanilla ES6+ JS.
  • Backend: Node.js v24 + Express.js Single-Port Application.
  • Database: Native SQLite storage (`database.sqlite`) with parameterized SQL statements.
  • Security: bcryptjs password hashing + JWT stateless authorization tokens.

User Role Permissions

  • Administrator: System policies, librarians management, deleting records, audit trails.
  • Librarian: Book circulation (issue/return), book inventory cataloging, member registration.
  • Student: Catalog search, personal loan status, active due dates, and fine alerts.

Frequently Asked Questions (FAQ)

1. How are overdue fines calculated?

The system tracks calendar days after the loan due date. An overdue fine rate (default ₹5.00/day) is automatically computed each day until the book is received at the Return Desk.

2. Can a student borrow an out-of-stock book?

No. The database prevents issuing any book whose available copies count is 0. Once a borrowed copy is returned, available copies immediately increment, making the title available again.

3. Where is the data stored? Does it survive server restarts?

All records are persistently written to database.sqlite on disk. Restarting the Node server preserves all books, members, issues, fines, and audit logs.

4. Can students extend or renew their book loans?

Yes! Students can renew any active, non-overdue loan by clicking "Renew (+14d)" on their My Borrowed Books page. Overdue loans cannot be renewed until pending fines are cleared.
